#### 3. `WPARAM` dan `LPARAM` jangan cuma teori

Buat latihan seperti:

```cpp
case WM_MOUSEMOVE:
{
    int x = GET_X_LPARAM(lParam);
    int y = GET_Y_LPARAM(lParam);
}
break;
```

Lalu:

```cpp
case WM_KEYDOWN:
{
    if (wParam == VK_ESCAPE)
    {
        PostQuitMessage(0);
    }
}
break;
```

Jadi pembaca memahami bahwa:

```text
WPARAM
LPARAM
```

bukan sekadar "tipe data aneh dari Windows", tetapi memang digunakan membawa data event.

### Dan tambahkan satu aturan ke prompt Agy:

> **Jangan memperkenalkan abstraction/framework sebelum pembaca memahami API Win32 mentah yang mendasarinya.**

Misalnya jangan langsung:

```cpp
Window window;
window.show();
```

Tetapi pembaca harus terlebih dahulu pernah menulis:

```cpp
RegisterClassExW(...);
CreateWindowExW(...);
ShowWindow(...);
UpdateWindow(...);
```

Baru setelah itu boleh dibuat helper/class.

Dengan begitu, ketika nanti kamu belajar DWM dan melihat kode seperti `DwmExtendFrameIntoClientArea()` atau `WM_NCHITTEST`, kamu **benar-benar tahu window yang sedang dimodifikasi itu dibuat dan bekerja bagaimana**, bukan cuma copy-paste snippet dari Stack Overflow.
